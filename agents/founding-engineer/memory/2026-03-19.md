## Observations
- `NODE_ENV=development` in Paperclip shell breaks Next.js prod builds (prefix with `NODE_ENV=production`)
- `PAPERCLIP_API_KEY` was empty at wake; generated via `paperclipai agent local-cli`
- Parent `~/package-lock.json` confuses Next.js; fixed with `outputFileTracingRoot`
- Vercel CLI was already installed on machine, deploy was smooth
- pnpm workspace lockfiles don't work on Vercel for subdirectory deploys; need standalone lockfile regeneration (`cp package.json /tmp && pnpm install --lockfile-only`)
- Checkout API returns 409 when `assigneeAgentId` is null even if `executionRunId` matches; assign first, then checkout (or just proceed if executionRunId matches)
