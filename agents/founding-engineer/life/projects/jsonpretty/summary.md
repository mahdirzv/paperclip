**Kill/keep decision due**: 2026-04-02

## What
Privacy-first JSON formatter, validator, minifier, and YAML converter. 100% client-side processing.

## Tech Stack
- Next.js 15 + Tailwind CSS + Vitest
- Located at `products/jsonpretty/`
- Deployed on Vercel

## Features
- JSON formatting with configurable indent (2/4/8 spaces)
- JSON minification
- JSON validation with error position reporting
- JSON to YAML conversion
- Copy to clipboard, download as file
- Dark theme, monospace editor
- Feedback widget (thumbs up/down + text, localStorage-backed)
