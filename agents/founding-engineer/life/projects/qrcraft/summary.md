# QRCraft

Second micro-SaaS product. Free, privacy-focused QR code generator.

- **Live URL**: https://qrcraft-five.vercel.app
- **Code**: `products/qrcraft/`
- **Stack**: Next.js 15, React 19, Tailwind CSS v4, qrcode lib, Vitest
- **Analytics**: Vercel Analytics + optional Plausible
- **Deployed**: 2026-03-19 to Vercel

## Features
- 7 QR types: URL, text, WiFi, vCard, email, phone, SMS
- Dedicated landing pages: `/wifi`, `/vcard`
- Custom colors, error correction levels, adjustable size (128-1024px)
- Download as PNG, copy to clipboard
- 100% client-side — no data sent to servers
- SEO with structured data (Schema.org WebApplication)
- Feedback widget (localStorage-based)
- Pro waitlist (localStorage-based)
